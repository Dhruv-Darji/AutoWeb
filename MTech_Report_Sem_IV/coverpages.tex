\addcontentsline{toc}{chapter}{Abstract}\index{Abstract}
\begin{center}
{\Large \bf Abstract}\\
\end{center}
\vspace{10pt}

Web automation using natural language prompting is essential for wide range of functionality including UI Testing, bug detection, bug replay, as well as frequent task automation. Traditional automation strategies such as random based, rule based and script based lack with diverse and dynamic UI operability. This experiment utilizing recent developments in Large Multimodal Models (LLMs) and investigates an agent architecture that take input of both the rendered webpage screenshot and a summary HTML, and generate next executable step actions in structured JSON format. We provide implementation using Qwen2.5-0.5B as well as Qwen3-0.6B in local system and detailing three innovations: DOM Delta implementation, QLORA-based fine-tuned filter, and privacy aware Human-in-the-loop, and we describe the design of our pipeline. Our initial experimental result demonstrate that using dom delta and local small fine tuned 0.5/0.6B filter, recall@20 is comparable with 3B filter. Results also suggest that with further refinement, resource-efficient multimodal can also offer flexibility, generalization, and safer automation for modern web interfaces. \\
