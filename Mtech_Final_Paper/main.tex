\begin{abstract}
Web automation using natural language prompting is essential for wide range of func- tionality including UI Testing, bug detection, bug replay, as well as frequent task au- tomation. Traditional automation strategies such as random based, rule based and script based lack with diverse and dynamic UI operability. This experiment utilizing recent de- velopments in Large Multimodal Models (LLMs) and investigates an agent architecture that take input of both the rendered webpage screenshot and a summary HTML, and generate next executable step actions in structured JSON format. We provide imple- mentation using Qwen2.5-0.5B as well as Qwen3-0.6B in local system and detailing three innovations: DOM Delta implementation, QLORA-based fine-tuned filter, and privacy aware Human-in-the-loop, and we describe the design of our pipeline. Our initial ex- perimental result demonstrate that using dom delta and local small fine tuned 0.5/0.6B filter, recall@20 is comparable with 3B filter. Results also suggest that with further re- finement, resource-efficient multimodal can also offer flexibility, generalization, and safer automation for modern web interfaces.
\end{abstract}
